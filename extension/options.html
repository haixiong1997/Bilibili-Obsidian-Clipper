配置指引

视频教程 · GitHub 仓库地址

  1. 在 Obsidian 社区插件市场安装并启用 Local REST API with MCP。
  2. 在插件设置中勾选 Enable Non-encrypted (HTTP) Server，地址通常为 http://127.0.0.1:27123。
  3. 复制 API Key，回到本页填写“Local REST API 地址”和“Local REST API Key”。

支持变量：{{created}} / {{upload_date}} / {{author}} / {{bvid}}，示例：Clippings/Bilibili/{{created}}

填写完成后建议先点击下方“测试连接”。

Fast Note Sync（服务器直存）

可选配置。填写后可用视频面板上的“保存到 FNS”按钮，把字幕笔记直接写入 FNS 服务器上的同步项目（无需本地 Obsidian）。 在 FNS 管理后台右上角「Copy API Config」复制 API Token。

客户端类型须与 Token 绑定的一致（通常为 ObsidianPlugin）。填错会返回 315/314，可先用下方“测试 FNS 连接”验证。

笔记属性（Frontmatter）

勾选需要写入到 Obsidian 属性区的字段。

自定义属性
